安全与访问范围

网页访问口令用于进入本站，和 VRChat 账号密码不同。口令按访问入口生效，不会自动区分局域网和互联网；同一入口使用同一口令。

本机访问
仅本机使用时，监听回环地址。不要把账号服务端口直接开放到网络。
局域网访问
其他设备通过服务器的局域网地址访问，也应设置访问口令、限制可访问设备；HTTP 不加密口令和资料。
互联网访问
使用 HTTPS 和受保护的网关入口。应用口令不等于公网防护；本项目不包含公网防护体系，防火墙、证书、WAF、DDoS 防护及安全维护由部署者负责。

需要局域网和互联网分别使用不同口令时，应由部署者配置两个独立访问网关。网页不能查看或修改服务器网关口令。

账号服务兼容口令（高级）

此处只显示旧账号服务的配置状态，不代表网关是否受保护。双账号服务之间需要协调认证，网页不支持分别修改或清除服务口令；请由部署者统一维护。使用 nginx 等服务器网关时，访问口令在网关侧管理。

当前账号服务口令

应用统一访问密码

两个账号共用应用入口。部署者在服务器运行 python run.py --set-password 修改此入口密码；如指定数据目录，需使用相同的 --data-dir。局域网和互联网访问同一入口时使用同一密码。
